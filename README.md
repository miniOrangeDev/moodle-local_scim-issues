# miniOrange SCIM User Provisioning for Moodle — Issue Tracker

This repository is the **public issue tracker** for the `local_scim` Moodle plugin (miniOrange SCIM User Provisioning for Moodle).

The plugin automates user provisioning in Moodle — creating, updating, and deprovisioning users — through SCIM 2.0 integration with identity providers such as Microsoft Entra ID (Azure AD), Okta, and other standard SCIM 2.0 IdPs.

> **Note:** This repository does not host the plugin's source code. It exists solely so that users and reviewers have a public place to report bugs, request features, and track known issues.

## Reporting an issue

Before opening a new issue, please search [existing issues](../../issues) to check whether it's already been reported.

When reporting a bug, please include:
- Moodle version and PHP version
- The plugin version (`local_scim`)
- The identity provider you're using (Azure AD / Okta / standard SCIM / other)
- Steps to reproduce, and the expected vs. actual behaviour
- Any relevant SCIM audit log entries or error messages (redact tokens/credentials before posting)

For feature requests, describe the use case and what you're trying to achieve.
